# fe-next-bootstrap-starter

Next.js (App Router) + TypeScript, styled with **Bootstrap 5**.

## Stack
- Next.js 15 (App Router)
- React 19
- TypeScript
- Bootstrap 5 (imported in `app/layout.tsx` via `bootstrap/dist/css/bootstrap.min.css`)

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Build
```bash
npm run build
```
